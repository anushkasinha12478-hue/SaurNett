# SaurNet

AI-Powered Solar Energy Management Platform

## Features

- Solar Generation Monitoring
- Grid Sharing & Net Metering
- Anomaly Detection
- Computer Vision Panel Inspection
- AI Troubleshooting Assistant
- Report Generation
- Financial Analytics
- Carbon Footprint Tracking
- Service Center Locator
